# QDTranslate: ИИ-перевод для Qidian (起点读书)

Xposed-модуль для приложения **Qidian Reading** (`com.qidian.QDReader`). Он переводит интерфейс и текст глав с китайского на русский с помощью нейросетей. Переводчик встраивается прямо в приложение, как в Alipay: поверх экранов появляется кнопка **«译»**, а настройки открываются внутри Qidian.

* **Интерфейс.** Переводятся все `TextView`, подсказки и тосты. Новые строки собираются в пакеты, переведённые хранятся в словаре (SQLite). После первого прохода интерфейс показывается на русском сразу, без запросов к сети.
* **Главы.** Текст перехватывается *до* разбивки на страницы, поэтому читалка сама верстает русский текст. Глава переводится частями по абзацам, с глоссарием имён и контекстом предыдущей части. Результат кэшируется.
* **Аннотации и комментарии**, то есть длинные тексты в карточках, переводятся целиком.
* **Нейросеть выбирается в настройках.** Для глав и для интерфейса можно задать разных провайдеров. Например, интерфейс через бесплатный Google, а главы через LLM.

## Поддерживаемые провайдеры

| Провайдер | Цена | Из РФ | Комментарий |
|---|---|---|---|
| Google Translate (gtx) | бесплатно, без ключа | да | не LLM; подходит для интерфейса |
| Google Gemini | бесплатный тариф | нужен VPN | ключ: aistudio.google.com; хорошее качество |
| Groq | бесплатный тариф | нужен VPN | быстрый, но маленький лимит токенов в минуту |
| OpenRouter `:free` | бесплатно, ~50 запросов в день | с ограничениями | ключ: openrouter.ai |
| Cerebras | бесплатный тариф | нужен VPN | большой дневной лимит |
| Mistral | бесплатный режим | — | ключ: console.mistral.ai |
| Z.ai GLM-Flash | бесплатно | да | китайская модель, сильна в китайском |
| DeepSeek | платно, дёшево | да | одна из лучших моделей для китайского |
| GigaChat (Сбер) | Freemium | да | нужен сертификат Минцифры (см. ниже) |
| Ollama / LM Studio | бесплатно | — | модель на вашем ПК в локальной сети |
| Свой | — | — | любой OpenAI-совместимый `/v1/chat/completions` |

Названия моделей на бесплатных тарифах часто меняются. Кнопка **«Список моделей»** в настройках загружает актуальный список прямо у провайдера.
Новый OpenAI-совместимый провайдер добавляется одной строкой в `provider/Preset.java`.

## Установка

### Вариант А: без root (LSPatch)
1. Установите **LSPatch Manager** (форк JingMatrix: https://github.com/JingMatrix/LSPatch).
2. Установите APK модуля QDTranslate.
3. В LSPatch выберите установленный Qidian, затем «Пропатчить», режим **Local** (модуль подключается из установленного приложения, и его можно обновлять без перепатчивания). Уровень обхода подписи: 2.
4. Удалите оригинальный Qidian и установите пропатченный APK. Подпись изменится, поэтому поверх установить не получится.

> ⚠️ После перепатчивания может перестать работать вход через QQ/WeChat, потому что они проверяют подпись приложения. Входите по номеру телефона или паролю. Если не получилось, используйте вариант Б.

### Вариант Б: с root (LSPosed)
1. Установите модуль и включите его в LSPosed. Область уже указана: `com.qidian.QDReader`.
2. Принудительно остановите Qidian и откройте его заново.

### Первый запуск
1. В Qidian справа появится синяя кнопка **«译»**. Нажатие открывает настройки, долгое нажатие включает или выключает перевод, перетаскиванием кнопку можно переместить.
2. В разделе «Настройка провайдера» выберите провайдера, вставьте ключ и нажмите **«Проверить»**.
3. В разделе «Какие нейросети использовать» выберите провайдера для глав и для интерфейса, затем нажмите **«Сохранить»**.

## Как включить перевод глав (один раз на версию Qidian)

Классы читалки Qidian обфусцированы и меняются от версии к версии. Поэтому точка перехвата текста главы не зашита в код, а задаётся в настройках. Найти её помогает **режим разведки**:

1. Включите в настройках «Режим разведки», сохраните и перезапустите Qidian.
2. Откройте любую главу и пролистайте 2–3 страницы. Модуль сообщит тостами о находках.
3. Откройте лог: `/sdcard/Android/data/com.qidian.QDReader/files/qdt_discovery.log`. Можно через файловый менеджер с доступом к `Android/data` или командой `adb pull`.
4. В логе для каждого места, где появился текст главы, есть стек вызовов. Ищите метод приложения (не `java.*` и не `android.*`), который **возвращает String** с текстом всей главы, обычно на 2–5 строк выше `Cipher.doFinal` или `new String(byte[])`.
5. Впишите его в поле «Хуки текста глав» в одном из форматов:
   ```
   com.qidian.QDReader.xxx.ChapterContentLoader#a          (подменить возвращаемую строку)
   com.qidian.QDReader.xxx.Parser#b@arg0                   (подменить 1-й строковый аргумент)
   ```
   Можно перечислить несколько кандидатов, каждый на своей строке. Строки, начинающиеся с `//`, игнорируются.
6. Выключите разведку, сохраните и перезапустите Qidian.

Как работает подмена: если перевод уже есть в кэше, он подставляется мгновенно. Если глава грузится в фоновом потоке, модуль ждёт перевод до N секунд (задаётся в настройках). Если загрузка идёт в главном потоке, показывается оригинал, а когда перевод готов, появляется тост «Глава переведена — откройте её заново».

Записи `Canvas.drawText` в логе показывают, какой класс рисует страницы. Это помогает сориентироваться в jadx, если стек от расшифровки неочевиден.

## Глоссарий

Поле «Глоссарий», по одной паре на строку:
```
林动=Линь Дун
青阳镇=городок Цинъян
筑基=Возведение Основания
```
В запрос к модели попадают только термины, которые встречаются в текущей части главы. Имена без глоссария модель транслитерирует по системе Палладия.

## GigaChat
1. На developers.sber.ru создайте проект GigaChat API и скопируйте **ключ авторизации** (Authorization key). Вставьте его в поле «API-ключ».
2. Серверы Сбера подписаны корневым сертификатом Минцифры, которого нет в Android. Скачайте «Russian Trusted Root CA» с Госуслуг (gosuslugi.ru/crt), откройте `.cer` как текст (PEM, `-----BEGIN CERTIFICATE-----…`) и вставьте его в поле «Корневой сертификат». Сертификат добавляется к системным, проверка TLS не отключается.
3. Во Freemium-режиме запросы обрабатываются в один поток. Модуль и так переводит главы последовательно.

## Сборка

**Через GitHub Actions** (без Android SDK на компьютере): запушьте репозиторий. Workflow `.github/workflows/build.yml` соберёт APK, его можно скачать в разделе Actions → Artifacts.

**Локально** (Linux): нужны JDK 17, Android SDK и Gradle 8.11+.
```bash
gradle wrapper --gradle-version 8.11.1   # один раз
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## Структура
```
hook/Entry.java          точка входа Xposed, только главный процесс Qidian
hook/UiHooks.java        перехват TextView.setText/setHint и Toast
hook/ContentHooks.java   настраиваемые хуки текста глав
hook/Discovery.java      режим разведки
hook/FloatButton.java    плавающая кнопка «译»
ui/SettingsDialog.java   настройки внутри Qidian
core/Engine.java         очереди, пакеты, разбивка глав, ожидание и уведомления
core/Cache.java          SQLite-кэш (словарь интерфейса и переводы глав)
provider/*               Google, OpenAI-совместимые, GigaChat
```

## Ограничения и планы
* **H5-страницы** (WebView: магазин, некоторые акции) пока не переводятся. План: внедрение JS, который переводит DOM через мост в модуль.
* Тексты, которые нарисованы прямо на `Canvas` в кастомных view (не `TextView`), переводятся только через хуки глав.
* Бесплатные тарифы ограничены по запросам и токенам. Перевод одной главы занимает 3–8 запросов. При ответе 429 модуль ждёт и повторяет запрос.
* Модификация клиента нарушает условия использования Qidian, и аккаунт теоретически могут ограничить. Используйте на свой риск и только для личного чтения.
* Идеи: офлайн-перевод через ML Kit, упреждающий перевод следующей главы, экспорт и импорт словаря интерфейса.
